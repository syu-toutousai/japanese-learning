# 隠れ漢字 ・ ポケット（隐藏汉字口袋）

盘点**平时惯用假名、一还原本源汉字就瞬间顿悟**的高频词：ありがとう【有難う】、
ごめん【御免】、やっぱり【矢張り】、せっかく【折角】、ひいき【贔屓】、でたらめ【出鱈目】、
さすが【流石】、あいにく【生憎】……

一条词 = **假名 → 本源汉字 → 造词逻辑（解字）**。全部例句 pykakasi 振假名，
并配 Nadeshiko 真实台词原声场景卡。成品是单文件 `index.html`（约 5.9MB，内嵌全部音声，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/kakure-kanji-courseware/
```

## 增长闭环：查词 → 入袋 → 重建

### ① 查：moji / nadeshiko

```bash
moji せっかく --once                    # 释义、JLPT 标签、编号例句＋中文译文
nadeshiko search せっかく --once -n 3   # 真实番剧/日剧台词（含原声/截图 URL）
```

- `word`／`kanji`／`read`／`origin`（解字）四个字段是核心；
- 例句写 2 条，尽量用**假名形**（本课件的主题就是“假名背后有汉字”）；
- Nadeshiko 台词自带行内注音 `漢字(かな)`，build 时会转成 ruby。

### ② 入袋：往 kakure-kanji.json 里加一条

```json
{
  "id": "sekkaku", "word": "せっかく", "kanji": "折角", "read": "せっかく",
  "group": "adv", "level": "N3", "emoji": "🦌", "type": "副詞",
  "meaning": "特意、好不容易——费尽周折",
  "origin": "典出《后汉书》：为劝谏不惜「折角」（折断额角）力争，后引申为不辞辛劳、特意。",
  "examples": [{"jp": "せっかく来たのに、店が閉まっていた。", "cn": "好不容易来了，店却关门了。"}],
  "nadeshiko": []
}
```

### ③ 重建：一条命令自动生长

```bash
python3 build.py
# 例句/读音自动合成 TTS；本源漢字・造詞邏輯・運用填空・聴解判別四层题库自动 +1 组
```

## 题库（4 层 + 错题本）

- 🈶 **本源漢字**：给假名选汉字（ありがとう → 有難う？御免？済みません？）
- 🧩 **造詞邏輯**：给词选解字（为什么「せっかく」是“好不容易”？）
- ✍️ **運用填空**：例句挖掉假名词选回去
- 🎧 **聴解判別**：听音频判断用了哪个词
- 错题本 localStorage 键：`kakure-wrong`；外加「混合交错」「错题重练」

## 字段规范（items[]）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一，字母数字-_，同时作音频/题目前缀 |
| `word` | ✅ | 平时用的假名形（ありがとう） |
| `kanji` | ✅ | 本源汉字（有難う） |
| `read` | ✅ | 读音（TTS 与填空用） |
| `group` | ✅ | 必须是 groups 里的 id |
| `level` / `emoji` / `type` | ✅ | 展示用 |
| `meaning` | ✅ | 中文释义（一句话） |
| `origin` | ✅ | 解字/造词逻辑（本课件的灵魂） |
| `examples` | ✅ | `{jp, cn, src?}`，jp 尽量用假名形 |
| `nadeshiko` | ➖ | 真实台词 `{jp, en, cn, media, ep, at, url, audio, thumb}` |
| `note` | ➖ | 💡 补充提示 |
| `quizzes` | ➖ | 自作题（choice/judge/listen） |

> 注意：JSON 字符串值里禁止裸 ASCII 双引号，中文引语一律用「」。
