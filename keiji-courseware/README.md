# 接头接尾词 ・ 口袋图鉴（接辞ポケット）

一个**会长大**的词缀课件：遇到新的接头词（接頭語）・接尾词（接尾語），随手丢进
`pocket.json`，重跑一次 `build.py`——卡片、发音、题库自动重新长出来。
成品是单文件 `index.html`（约 1.5MB，内嵌全部发音，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/keiji-courseware/
```

## 增长闭环：查词 → 入袋 → 重建

日常扩充配合本机 **moji-dict** 技能（`moji` CLI 免登录查 MOJi辞書），三步一个循环：

### ① 查：用 moji 查词条、抄例句

```bash
moji ごと --once                    # 释义、JLPT 标签、编号例句＋中文译文
printf "1\n" | moji ごと --once     # 改选第 2 个候选
moji "皮ごと食べる" --once          # 整句输入＝反查例句库（结果列 [E0]…）
printf "0\n" | moji ごと -a --once  # 可选：把单词/例句真人发音下载到 ~/moji_audio/
```

- 从输出里抄三个字段：`word`／`read`／例句 `jp` 与译文 `cn`；
- 本课件的播放发音由 `build.py` 调 edge-tts 自动合成，**不需要手动下载音频**，
  `-a` 只在想额外留一份真人录音时才用；
- MOJi 是非官方免登录端点，请求保持少量即可。

### ② 入袋：往 pocket.json 里加一条

```json
{
  "id": "gachi", "type": "suffix", "word": "〜がち", "read": "がち",
  "group": "derive", "level": "N3", "emoji": "🌧️",
  "meaning": "容易～、往往～（多用于消极倾向）",
  "examples": [{"jp": "冬は運動不足になりがちだ。", "cn": "冬天容易缺乏运动。"}],
  "note": "接动词ます形去ます；多接消极倾向。"
}
```

### ③ 重建：一条命令自动生长

```bash
python3 build.py
# 新例句的发音自动合成缓存；詞義認識／運用填空／聴解判別三档各 +1 問
```

词条越多题库越大——口袋的价值随收藏一起增长。

## 往口袋里加词条（字段规范）

1. 打开 `pocket.json`，复制一条现有条目，改字段；
2. 存盘后运行 `python3 build.py`（校验不通过会逐条列出问题）；
3. 刷新 `index.html` 即可。新例句的发音由 edge-tts 自动合成缓存。

### 条目字段

```json
{
  "id": "san",
  "type": "suffix",
  "word": "〜さん",
  "read": "さん",
  "group": "honor",
  "level": "N5",
  "emoji": "👤",
  "meaning": "接在人名后的一般敬称，男女通用，最常用",
  "examples": [
    {"jp": "田中さんは事務所にいます。", "cn": "田中先生在事务所。"}
  ],
  "note": "不能加在自己或自己一方的人身上。",
  "quizzes": [
    {"type": "judge", "q": "私は王さんです。", "ans": false, "exp": "…"}
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✔ | 全局唯一，字母数字-`_`；**定了就别再改**（错题本靠它记忆） |
| `type` | ✔ | `prefix`（接頭語）/ `suffix`（接尾語） |
| `word` | ✔ | 展示形态，词缀部分用 `〜` 占位，如 `お〜`、`〜さん` |
| `read` | ✔ | 词缀读音（假名），也是单独朗读的文本 |
| `group` | ✔ | 所属分组 id（在顶部 `groups` 里定义名称与配色） |
| `level` | ✔ | JLPT 档位标签，如 N5–N1 |
| `meaning` | ✔ | 中文释义（「認識」题的答案来源） |
| `emoji` |  | 卡片图标，缺省 📌 |
| `examples` | ✔≥1 | 例句 `jp` + 中文 `cn`；每句自动合成发音 |
| `note` |  | 金色小贴士 |
| `quizzes` |  | 自作题：`choice` / `judge` / `listen`；listen 的 `aid` 填例句序号（0 起） |

### 题库是自动生成的

- 📘 **詞義認識**：每个词条一题，干扰项取自同类型其他词缀的释义；
- ✍️ **運用填空**：从例句里挖掉词缀（自动识别 `〜` 后的核心形式）选回去；
- 🎧 **聴解判別**：听例句判断用了哪个词缀；
- ⭐ **自作題**：条目里 `quizzes` 写了就收录；
- 📕 **错题本**：localStorage 存储，做对即移出；词条删除后失效引用会自动跳过。

## 内容页签

🗺️ **一覧**（按功能分组总览）→ 📖 **詳細**（卡片＋例句原声）→ 🎯 **クイズ**

内置 25 个高频词缀起步（お〜/ご〜、さん/ちゃん/くん/様、〜中(ちゅう/じゅう)、
〜ぶり、屋/家/員/者、料/費/代/賃、的/化/やすい/にくい……），按 7 组分类，
可直接删改成自己的收藏。

## 设计依据（人脑语言习得机制）

| 特性 | 对应机制 |
|---|---|
| 按语义场分 7 组而非音序排列 | 组块化 chunking |
| 每词一个 emoji 图标 | 双重编码 dual coding |
| 例句挖空选词缀（运用档） | 生成效应 generation effect |
| 听例句辨词缀（听解档） | 声音与形义绑定 |
| 干扰项优先取同类近义前/后缀 | 对比分析 contrastive analysis |
| 🎲混合交错模式 | interleaving 交错练习 |
| 📕错题本（做对即移出） | error-driven review |

## 重新构建

```bash
python3 build.py
```

- 发音按**文本哈希**缓存于 `audio/*.mp3`：改了句子自动重录该条；删掉某条 mp3 也强制重录；
- 不再被引用的旧缓存会在构建时自动清理；
- 某条发音合成失败只跳过该处播放键，不影响整体构建（结尾会列出失败清单）。
