# 見えない助詞 ・ 句法の省略と中止形

一本专讲「**助词失踪现场**」的课件：日语句子里的助词往往不现身——「ご飯食べる？」少了 を、
「天気いいね」少了 が/は、「脱ぎ、入った」用**連用形中止**代替了 て、「降り続く雨。」用
**体言止め**收尾……省略/中止是**文法的本体**，语序、活用形、停顿把语法关系稳稳扛住，字面上的
空格和标点只是把它「变醒目」的表现层。

遇到新句式随手丢进 `mienai.json`，重跑一次 `build.py`——卡片、发音、题库自动重新长出来。
成品是单文件 `index.html`（内嵌全部发音＋Nadeshiko 原声，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/mienai-courseware/
```

## 四大分類（28 句式）

| 组 | 内容 | 真話 |
|---|---|---|
| ◌ 零助詞（13） | を/が/は/に・へ/で/か 的省略、願望句、重合ゼロ、だゼロ，以及两条规则：**復元容易性**（省略的通行证）与**省略禁区**（对比焦点/正式度红线） | 语序为助词退役保驾护航 |
| 🔀 中止形（5） | 順序（〜て 代役）・因果（〜から 代役）・対比（〜が 代役）・並列・書面「〜し」中止 | **接续力在活用形，逗号只是显示边界** |
| ✂️ 係り切れ目（4） | 修饰的係り先（泣きながら、走る彼を…）・長い修饰切れ目・対比基準（〜より、）・倒置（いいよ、それ。） | 逗号＝切换修饰轨道的扳道闸 |
| 〰️ 言い切り（6） | 体言止め・見出し体・言いさし（けど。）・語気断ち（絶対ダメ。）・推量語尾（でしょう）・しり消し（…。） | 句号踩着语气刹车 |

## 增长闭环：发现句式 → 入册 → 重建

### ① 找素材：moji / nadeshiko 双源

```bash
moji 絶対 --once                      # 教科书例句（抄 jp/cn）
nadeshiko search "天気いい" --once -n 5   # 真实番剧/日剧台词（必带 --once）
```

- 教科书例句抄进 `examples[]`（每条约 2–3 句，`jp` + 中文 `cn`）；
- 真实台词按结构 `{ "jp","en","cn","media","ep","at","url","audio","thumb" }`
  放进条目的 `nadeshiko[]` 数组，build 自动下载原声并渲染场景卡（缩略图＋▶）。
  jp 里的汉字一律用「」，别写裸 ASCII 双引号；
- 口语范例（零助詞/言い切り 常用名）大多没有 MOJi 词条——直接用中文按日式口语造句即可，
  TTS 负责发音；
- 正式/书面例句（中止形）多来自教科书改写，src 可不标或标 `"src":"moji"`。

### ② 入册：往 mienai.json 里加一条

```jsonc
{
  "id": "ga",
  "word": "天気いいね",
  "read": "てんきいいね",
  "tag": "格助詞ゼロ（主語）",
  "drop": "が",               // 零助詞组：被省略的助词（自动生成「補格填空」题）
  "standard": "天気がいいね", // 零助詞组：助词在位时的标准形（补格题的答案还原）
  "role": "next",             // 中止形组：next/cause/contrast/parallel/polite（自动生成「中止形判別」题）
  "group": "zero", "level": "N4", "emoji": "☀️",
  "meaning": "描述天气/状态的 主语 が 常连同 は 一起消失……",
  "examples": [
    { "jp": "今日天気いいね。", "cn": "今天天气真不错啊。" }
  ],
  "nadeshiko": [ /* 可选，见上 */ ],
  "note": "金色小贴士（语感/规范提醒）"
}
```

### ③ 重建：一条命令自动生长

```bash
python3 build.py           # 新音自动合成；働き認識／補格填空／中止形判別／聴解判別各 +N 問
```

## 条目字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✔ | 全局唯一，定了别改（错题本靠它记忆） |
| `word` | ✔ | 展示的句式/例句（如 ご飯食べる？／脱ぎ、入った。） |
| `read` | ✔ | 假名读音，也是单独朗读的文本 |
| `tag` |  | 句式类型徽标（格助詞ゼロ／中止形（順序）／切れ目／言い切り…） |
| `drop` |  | （零助詞）被省略的助词 → 自动出「補格填空」 |
| `standard` |  | （零助詞/中止形）助词在位时的标准形 → 详情里显示「◌ 助词在位时」 |
| `role` |  | （中止形）next/cause/contrast/parallel/polite → 自动出「中止形判別」 |
| `group` | ✔ | 分组 id（顶部 `groups` 定义名称与配色） |
| `level` | ✔ | JLPT 档位标签 |
| `meaning` | ✔ | 中文解释（「働き認識」题的答案来源） |
| `examples` | ✔≥1 | 例句 3 条上下（`jp` + 中文 `cn`），每条自动合成发音并加 pykakasi 振假名 |
| `nadeshiko` |  | 原声台词数组 → 「🎬 原声台词」场景卡（自动振假名） |
| `note` |  | 金色小贴士（💡 教学提示/规范提醒） |
| `quizzes` |  | 自作题：`choice` / `judge` / `listen` |

> 例句展示层由 build 自动加 **pykakasi 振假名**（只作用于 display 副本，TTS/出题/填空用素文），
> 页面里 `<ruby>` 即浏览器原生注音。

## 重新构建

```bash
python3 build.py
```

- 发音按**文本哈希**缓存于 `audio/*.mp3`，改句自动重录、旧缓存自动清理；
- Nadeshiko 原声与缩略图缓存于 `nade_audio/`（已 gitignore，可重新下载）；
- 某条合成失败只跳过该处播放键，不影响整体构建（结尾列出失败清单）。

同系列姊妹篇：「兼類詞」口袋见 `../kenrui-courseware/index.html`，
「断定の「に」統一引擎」见 `../ni-courseware/index.html`。
