# 日本語の二重構造 ・ メタ認知ガイド

「汉字溯源」「连用形溯源」到底该怎么用？——本页是一张**手写单文件**的元认知指南（无构建脚本、
无 TTS/题库管道），回答十二个问题：

1. **日语是什么结构？** 原生日語コア（声音↔情境直连）＋外源映射层（漢字訓読・当て字・漢語・外来語）
2. **拆解什么时候可信？** 区分「真語源」（命中母语者隐性语感）与「当て字」（只是记忆脚手架）
3. **怎么判断？** 真語源／当て字／漢語変遷／熟字訓／諸説あり／未詳 六分类 ＋ 判定四问
4. **它的动力学是什么？** ベクトルモデル（二轴）：縦＝文法化度（実語→機能語）、横＝表記（漢字⇄かな）。
   「隠れ漢字」横跨四象限；只有右下（かな×機能）才是「进行中的文法化」的可见矢量——
   当て字是反方向（かな→漢字）的正交现象，与语法化无关。
5. **怎么不被教材/老师带偏？** 語源主張の検品法——語源謬誤（etymological fallacy）・民間語源の罠。
   「語感の本体か、記憶フックか」ワンクリック検品器＋ありがちな誤りの対照表（矢張り／っぱなし／素敵）。
6. **这工程什么时候开始的？现在还在动吗？** 地層年表——上代の借字・万葉仮名（音→）、奈良〜平安の訓読体系化
   （←義）、仮名の発生（逆方向）、江戸の当て字ブーム、明治の訳語＋言文一致、昭和の国語改革、そして現在進行形
   （常用漢字改定・こども表記・キラキラネーム・令和・IME 変換＝リアルタイムのマッピングエンジン）。**終点はない。**
7. **複合動詞か、副詞か、それとも接尾辞か？** 「あまり＋慌てる」を V₁連用形＋V₂ と読む視点から出発し、
   **挿入テスト**（間に語を挟めるか）＋「具体は溶接・抽象は自由」の新次元＋文法化の二経路
   （独立副詞 vs 文法化接尾辞）＋経路 A の**脱漢字**まで。附 5 题插入小测。
8. **文法化的词，写法为什么会变？** 表記の黄金律——**具体は漢字、機能はかな**。三大「脱漢字」陣営
   （形式名詞こと・もの・ところ／補助動詞〜てみる・〜ておく／接続詞したがって・しかし）、
    認知メカニズム（漢字＝表意チャンクの画面レンダリング、かな＝文法の接着剤）、
    「語感はすでに規範」——公用文作成の考え方（令和4年）・記者ハンドブック・NHK漢字表記辞典、
    最小対比（空を見る⇄食べてみる）と検品四問、N1 読解・作文への実用、12 题表记小测＋拓展阅读。
9. **身体語彙はなぜ和語ばかり？** 身体語彙の二重構造——和語の動作層（部位＋助詞＋和語動詞の比喩転用：
   手を焼く・足を運ぶ）vs 漢語の概念層（二字熟語・サ変：閉口・手腕・念頭・目撃）。判定は「読み」で行う
   （目安＝和語／手腕＝漢語）。混種語（怪訝な顔）と、真題コーパスに残した漢語身体語彙の位置づけも。
10. **日本語は誰の目で語るか？** 視点と主観性——出来事を話し手の視点に引き寄せ、感情や文脈まで
    主体的にコントロールする言語である、という命題を三方向から解剖する：① 出来事（やりもらい動詞の三点視点・
    迷惑の受身・自発・〜てくる）、② 感情（感情形容詞・助動詞「たい」の人称制限——三人称は 〜がる／〜そうだ）、
    ③ 文脈（文末表現の確信度・証拠の種類、終助詞よ・ね、〜のだ）。④ 学習効果の仮説——この文法が毎文
    「私はどちら側か／内か外か／今どう感じるか／どれだけ確信するか」を先に決めさせ、**主体性（agency）を訓練する**
    （ただしラベル付きの仮説として。効果は個人差・実証途上）。⑤ 視点の倫理——**神の視点（俯瞰・全知＝自大）vs
    個の視点（局限の自覚＝自謙）**、**他者の内心はブラックボックス**（投影の禁絶＝人称制限の認識論的読み。
    内心の断定は不可、様態・行動・引用・推量という証拠つきの窓のみ）、そして社会副作用の「功罪」両読み
    （共感の自粛・空気読み内耗・無責任・孤立 ⇄ 敬意・自律尊重。言語決定論は退け、affordance としてラベル付き）。
    ⑥ その先の誘惑の検品——**投射＝表演**論（共感のシミュレーション説・ゴフマンのドラマツルギー。
    日本語は表演を禁じるのではなく「出典表示」を義務づける）、**反宏大叙事**説（政治レジスター・戦時動員という反例。
    過剰一般化と判定）、**言語決定論**（検品四問——因果の向き・レジスター・相関/因果・集団診断。弱いサピア＝ウォーフまで。
    「防腐剤」「双極」はモデル＝脚手架であり実体ではない）。
    ⑦ 最終検品と出口——**虚構宣言**（社会診断は領分の外。「ある社会」等はフィクションの小道具）、
    **登りすぎの三警戒標識**（病名メタファー＝レッテル／「教えること＝戦略効果」＝検証不能／「生命力」＝詩）、
    そしてマイクロ実践（音読・Nadeshiko 一行・**過去問一問の視点メモ**）＋**N1 題型↔視点篇の対応表**。
    池上嘉彦の**主観的把握 vs 客観的把握**、中国語母語者の落とし穴（给／他很高兴／被）と参考文献リンク付き。
11. **「もう」はなぜ「すでに」とも「さらに」とも訳せるのか？** 時間篇——テンスとアスペクト。
    「もう一度＝再／もう終わった＝已经／もう来るだろう＝马上」と一語が複数の時間方向を指す謎から出発。
    辞書は**一語**として扱い（デジタル大辞泉 5 語義：すでに・まもなく・追加・反復拒否・強調）、
    語源は**諸説あり**（精選版 日本国語大辞典：副詞「も」と同語源、成立の前後は不明、ロドリゲス文典に「マウハヤ」）。
    統一モデルは**局面（段階）の境界のそば**——手前（まもなく）／通過（すでに）／その先（追加）／限界（拒否）。
    **テンス（時制）とアスペクト（相）**を二本の物差しとして区別し、検品（英語にもアスペクト・日本語にもテンス）、
    現場三つ——**発見・確認の「た」**（あった！）、**〜ている**の進行/結果の状態（金田一以来の分類）、
    **従属節の相対テンス**（行くとき/行ったとき）、**「まだ」＝局面の鏡像**、話者の「いま」の幅（さっき/もうすぐ）。
    さらに**認知のアンラーニング**仮説（線形時間の物差しを外す・梯子は降りたら外してよい。ラベル付き）と
    N1 題型対応表（問題5/問題7/読解/聴解）。10 题时间小测付き。
12. **文法の全部門は、一つの「相」に還元できるのか？** 相の統一モデル（Unified Aspectual Model）。
    発端の一文「来月から大阪支社に行くことにしました」の「から」——属するのは内側の出来事「大阪支社に行く」であり、
    「にしました」（決定）ではない（決定は発話の場で完結し、来月は決定された出来事の内部の起点）。
    アスペクト＝**動作を描く次元・切片**（テンス＝撮影時刻、アスペクト＝シャッター・フォーカス・フィルター）、
    テンス＝その一投影（**時間距離相**）——「あった！」は相変のいまの落定として読める（ただし過去用法は現にあり、実体化しない）。
    活用＝基礎の相スイッチ（未然形＝未実現相／連用形＝接続・過渡相／終止形・連体形＝自己完結相）、
    補助動詞＝過程と空間の切片（〜てしまう＝不可逆完了相・〜ておく＝準備留置相・〜てみる＝試行認知介入相・
    〜ていく/〜てくる＝時空流動相・〜てある＝結果の状態の意図的残存）、受身・使役＝**力動相**、
    文末表現（らしい・ようだ・そうだ）＝**認識・情報顕現相**、授受＝**利益場域相**。接続詞＝**命題間の認識相**——
    すなわち/つまりは枠内換言で命題の事実性に触れず（仮説・思弁の枠でも安全）、だから/ですから/したがっては
    推論関係の成立にコミットする（ですからは敬体で常体の学術文に文体不合）。
    統一表と相のスタック図（［動詞核心］＋［過程］＋［力動］＋［認識］＋［利益］）、
    学習実践（フォームを相の部署に配属する五つの問い・対で覚える・読解の一行メモ）、N1 題型対応表、
    検品（テンスは消えない・用語は学校文法のまま・モデルは脚手架）。16 题统一小测付き。

## 维护约定

- 本目录**没有 build.py**：`index.html` 手写维护，改完即提交。
- 新增课件或发现新的语源判定案例时：
  1. 更新 `index.html` 的六分类例词与分类小测（`QS` 数组）；
  2. 若是新词条，优先落到对应课件的源流徽标（kakure-kanji）或链路（renyo）；
  3. 新的挿入テスト事例は `IINS` 配列（現在 5 問）へ追加する；
  4. 新的表記事例は `KQS` 配列（現在 12 問）へ追加する。規範の記述は「公用文作成の考え方」（令和4年）を
     一次資料とし、媒体差（全て／すべて 等）はハウススタイルとして注記する。
  5. 身体語彙の語種（和／漢／混）は `karada-courseware/karada.json` の `origin` 字段が一次データ。
     新規追加時は読み（訓／音）で判定し、非和語なら explicit に `origin` を書く（既定＝wago）。
     本文 `#body-layers` セクションと件数がずれたら両方更新する。
   6. 新しい視点・主観性の事例は `VQS` 配列（現在 21 問）へ追加する。用語は学校文法に合わせる
      （受身・自発・終助詞・文末表現・補助動詞。JSL の 可能形／て形 等は使わない）。
      参考文献リンクは 辞書（コトバンク）・Wikipedia・NDL サーチの実在ページのみを張る。
   7. 新しい時間・アスペクトの事例は `MQS` 配列（現在 10 問）へ追加する。「もう」の語義は
      コトバンクのデジタル大辞泉・精選版日本国語大辞典を一次確認とし、語源は断定せず `諸説あり` の
      ラベルを守る（「もはやの転訛」は推測止まり）。テンス・アスペクトの二分法も重心のモデルとして扱い、
      実体化しない（英語にもアスペクト・日本語にもテンス）。
   8. 新しい相の統一モデルの事例は `UQS` 配列（現在 16 問）へ追加する。用語は学校文法のまま
      （未然形・連用形・終止形・連体形・助動詞・補助動詞・受身・使役・文末表現。JSL の ます形／て形 等は使わない）。
      テンスをアスペクトの投影として読むのは重心のモデルであり、実体化しない（〜た の過去用法は現に存在し、
      過去用法こそ最重要の一つ）。相のラベルは読解・予測の道具として使い、ラベル自体を目的にしない。
      接続詞の事実性（すなわち＝枠内換言／だから・したがって＝推論へのコミット）も重心のモデルとして扱い、
      「だからは仮説に使えない」のような二分法にしない。
- 判定有争议的词一律标 `諸説あり`，不要把当て字包装成定论。
