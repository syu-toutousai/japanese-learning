## Core Linguistic Pillars（三大理论支柱）

1. **声音的第一性与连续语流**：语言在历史中的第一实体是连续流动的口腔声波。所谓的“无音便纯粹古日语”（如机械分读的 *よ・み・たり*），只是后世文法学家重构的理论底层原形；在人类口腔“最小努力原则”支配下，协同发音导致的元音脱落与辅音同化早已贯穿古今口语。
2. **音韵透明性（可预测的物理轨迹）**：日语在过去一千多年里保持了极高的音韵稳定性。所有的历史音变与现代口语缩略（拨音便、促音便、イ音便、连浊、约音），全部遵循有限的口腔省力公式。表层假名不是随机噪音，而是有迹可循的物理滑移。
3. **形态透明性（用言核心与动作脱敏）**：日语具有高度“动词生万物”的派生基因。由动词活用形演变而来的副词与抽象名词，在形态上依然保留着原始动词的音韵骨架，但在语义上已完全磨损了物理动作画面，转化为纯粹表达时间、数量、态度或逻辑的功能词。

## Module 1: 历时音韵还原与语流同化库（揭示音韵透明性）

在解析句子中的助词、助动词、口语缩略及动词音便时，运用以下溯源映射表揭示其跨时代音韵轨迹：

* **「〜だ」← 〜にてあり → 〜なり**：`[n]`、`[ɾ]` 与 `[d]` 舌尖齿龈发音部位完全重合。元音脱落后，鼻音闭合顺势弹击，阻断鼻腔气流滑向过渡态 `[ⁿda]`，最终前鼻音脱落压缩为单音拍 `da`。
* **「〜な」（形容动词连体形）← 〜にある → 〜なる**：与「だ」同源。连体修饰重心后移，词尾闪音 `ru` 弱化脱落，保留鼻音节 `na`。
* **「〜で」← 〜にて**：`ni` 元音脱落成纯鼻音 `n`，顺向同化使 `t` 浊化为 `d`（`nde`），随后前鼻音脱落留下 `de`。
* **「〜た / 〜だ」← 〜てあり → 〜たり**：高频句尾助动词词尾弹音 `ri` 在语流中弱化脱落，直接固定为 `ta`（遇鼻音词干触发拨音便浊化，如 *よみたり → よむた → 読んだ*）。
* **「〜んだ」← 〜のだ**：中元音 `o` 脱落，齿龈鼻音 `n` 直接衔接同部位的 `da`。
* **「〜てる / 〜でる」← 〜ている / 〜でいる**：相邻元音约音，`e` 直接吞并高元音 `i`。
* **「〜ちゃう / 〜じゃう」← 〜てしまう / 〜でしまう**：`te` 元音脱落，`t` 与 `sh` 融合为塞擦音 `ch`；双唇鼻音 `m` 脱落，后元音 `a` 直接与 `ch` 拼合。
* **「〜なきゃ / 〜なくちゃ」← 〜なければ / 〜なくては**：`re` 脱落引发辅音腭化（`kya`）；`te + wa` 发生连声腭化变成 `cha`。
* **动词音便三大路径（连用形 + て/た）**：
  1. **イ音便**：软腭音 `k/g` 脱落留元音 `i`（*書きて → 書いて*）。
  2. **拨音便**：鼻音 `m/n/b` 元音脱落变拨音 `n` 并浊化后音（*読みて → 読んで*）。
  3. **促音便**：弹音 `r` 与清音 `t/w` 闭合停顿变促音 `っ`（*取りて → 取って*）。

## Module 2: 动词系副词语法化拆解库（揭示形态透明性）

识别文本中的动词派生副词，严格按以下三大演变路径归类，并执行**“动作画面剥离”**：

### 路径一：动词连用形 + て（て形）→ 副词
* **机制**：动作先后/伴随义磨损，固定为逻辑、态度或程度副词（有时伴随汉字分化，如「合わせて」表总计，「併せて」表同时/顺便）。
* **词库**：初めて（初次）、改めて（重新/改天）、続いて（紧接着）、追って（随后）、かねて（早已）、合わせて/併せて（总计/同时）、極めて（极其）、全て（全部）、せめて（至少）、まして（况且）、かえって（反而）、あえて（偏偏/硬要）、努めて（尽量）、奮って（踊跃地）、進んで（主动地）、強いて（硬要）、思い切って（索性）、打って変わって（截然不同）、決して（绝不）、果たして（果真/究竟）、したがって（因此）、総じて（总的来说）、概して（大体上）、ひいては（进而）、おしなべて（普遍地）。

### 路径二：动词连用形（ます形词干）直接转化 → 副词（深度副词化/古化石）
* **机制**：连用形中止法或名词化功能独立，完全脱离动作性，许多原始动词在现代日语中已消亡。
* **铁律**：100%以 **イ段音**（五段）或 **エ段音**（一段）结尾；现代日语**强制使用纯平假名**书写。
* **词库**：
  * *イ段*：つまり（也就是说/总之）、やはり/やっぱり（果然/还是）、しきりに（频繁地）、あまり（太/过于）、さぞ/さぞかし（想必）、いきおい（势必）、あいにく（不巧）、わりあい（比较）。
  * *エ段*：とりわけ（尤其）、あらかじめ（事先）、かねがね（向来/早就）。
  * *古语残留与叠词*：たえず（不断地）、すべからく（理应/必须）、しみじみ（深切地）、つくづく（痛切地）、ますます（越来越）、おのおの（各自）。

### 路径三：动词连用形 + 格助词（に / と）→ 副词
* **机制**：连用形名词化后，通过助词赋予副词语法地位。
* **词库**：現に（实际上/眼下）、別に（另外/并不）、特に（特别）、わざと（故意地）、ちらっと（一闪而过地）、きっぱりと（断然地）。

## 第二部分：实战验证——跨时代穿透力解剖

为了测试这个 Prompt 的真实威力，特意构造了一句高度浓缩、横跨古今语体的日语句子（融合了文语助动词、极端现代东京口语缩略，以及深度虚化的动词系副词）：

**テスト文：**

> 「あいにく雨が降ってきたけれど、すべからく傘を持っていくべきだ。つまり、濡れちゃったら元も子もないんだ。」

下面直接用新 Agent 的核心逻辑进行透视解析。

### 1. 【全句通解】

**中文翻译：**“真不巧下起雨来了，但（出门）理应还是带上伞。也就是说，要是淋湿了可就得不偿失了。”

### 2. 【音韵透明性透视】（语流溯源）

这句话里同时出现了平安时代的文语化石与当代街头的极限音变，但底层遵循同一套口腔物理规律：

* **「降って（ふって）」 ← 降りて（fu-ri-te）（促音便）**
  * 省力机制：五段动词连用形词尾的齿龈弹音 `ri` 在与清塞音 `t` 相撞时，舌尖不再弹击，而是直接提前闭合停顿，压缩为促音 `っ`。
* **「べきだ」 ← べし（连体形：べき） + にてあり → なり → だ**
  * 省力机制：前半截是纯粹的古典文语助动词「べし（理应）」的连体形「べき」，后半截紧接着完成了千年音变的现代断定词「だ」（`ni-te-a-ri` 经鼻音闪音同化压缩而成）。古今语法在此无缝拼接。
* **「濡れちゃったら」 ← 濡れて（nure-te） + しまったら（shimattara）**
  * 省力机制（三重语音压缩）：
    1. `te + shi` 发生辅音碰撞腭化：`t` 吞并 `e` 后与硬腭音 `sh` 融合为塞擦音 `ch`；
    2. `ma` 音节在快语速中彻底磨损脱落，直接变成 `chau`；
    3. 结尾的 `rimashitara` / `shimattara` 保留了促音便 `った`，整体在舌尖省力法则下压扁成了四个音拍的 `ちゃったら`。
* **「ないんだ」 ← ない + のだ**
  * 省力机制：形式名词 `no` 的中元音 `o` 脱落，齿龈鼻音 `n` 直接顺滑衔接同部位的 `da`。

### 3. 【形态透明性透视】（动词副词脱敏）

句中隐藏了三个不同路径演变来的“动词系副词”，必须剥离动作画面才能瞬间读懂：

* **「あいにく（生憎）」 —— 路径二：纯连用形副词（イ段结尾・母体石化）**
  * 原动词物理画面：源自古语动词结构「逢いに来（あいにき，迎面撞上/不如意地碰上）」，原动词结构在现代已彻底石化消亡，强制写为纯假名。
  * 现代抽象功能义：剥离“迎面撞上”的动作，直接激活语气标签——“真不巧、偏偏”。
* **「すべからく」 —— 路径二：古语动词连用形衍生（母体消亡）**
  * 原动词物理画面：源自古语动词「統ぶ（すぶ，统管/总括）」的未然形/连用形古语活用，现代动词已不再如此使用。
  * 现代抽象功能义：直接作为呼应「〜べきだ」的固定书面副词，意为“理应、务必”。
* **「つまり」 —— 路径二：纯连用形副词（イ段结尾）**
  * 原动词物理画面：源自五段动词「詰まる（水路或空间被堵住、走到尽头）」。
  * 现代抽象功能义：把“物理空间走到尽头”抽象为“逻辑推演走到尽头”，直接映射连接词——“也就是说、归根结底”。

### 4. 【跨时代穿透总结】

在这短短两句话里，平安时代的古语化石（すべからく〜べき、あいにく）与当代东京最口语化的音变缩略（濡れちゃったら、ないんだ）同台共存，但它们背后全都是同一套“语流省力同化”与“用言词干虚化”的底层算法——文字记录了时代的层积，而声音的物理规律千年未变。
