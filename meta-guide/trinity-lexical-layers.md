## Module 1: 历时音韵还原与语流同化库（揭示音韵透明性）
* **「〜だ」← 〜にてあり → 〜なり**：`[n]`、`[ɾ]` 与 `[d]` 舌尖齿龈部位重合，鼻音闭合顺势弹击滑向 `[ⁿda]`，最终压缩为单音拍 `da`。
* **「〜な」（形容动词连体形）← 〜にある → 〜なる**：词尾闪音 `ru` 弱化脱落，保留鼻音节 `na`。
* **「〜で」← 〜にて**：`ni` 元音脱落成纯鼻音 `n`，同化使 `t` 浊化为 `d`（`nde`），前鼻音脱落留下 `de`。
* **「〜た / 〜だ」← 〜てあり → 〜たり**：词尾弹音 `ri` 弱化脱落固定为 `ta`（遇鼻音词干触发拨音便浊化，如 *よみたり → 読んだ*）。
* **「〜んだ」← 〜のだ**：中元音 `o` 脱落，齿龈鼻音 `n` 直接衔接 `da`。
* **「〜てる / 〜でる」← 〜ている / 〜でいる**：相邻元音约音，`e` 吞并 `i`。
* **「〜ちゃう / 〜じゃう」← 〜てしまう / 〜でしまう**：`te` 元音脱落，`t` 与 `sh` 融合为 `ch`，`m` 脱落拼合为 `chau`。
* **「〜なきゃ / 〜なくちゃ」← 〜なければ / 〜なくては**：`re` 脱落引发腭化（`kya`）；`te + wa` 发生连声腭化变成 `cha`。
* **动词音便三大路径**：イ音便（`k/g` 脱落留 `i`）、拨音便（`m/n/b` 变 `n` 并浊化后音）、促音便（`r` 与 `t/w` 闭合停顿变 `っ`）。

## Module 2: 述语词中心派生与副词脱敏库（揭示形态透明性）
* **述语词 → 抽象体言**：状态述语词干 + `〜さ / 〜み`（如 *高さ、深み*）；动作述语连用形（如 *考え、動き*）；形式体言（*こと、の、もの*）将述语短语体言化。
* **路径一：动词连用形 + て → 副词**：动作伴随义磨损，固定为逻辑、态度或程度副词（如 *初めて、改めて、合わせて/併せて、極めて、せめて、まして、かえって、あえて、決して、果たして、したがって、総じて*）。
* **路径二：动词连用形（ます形词干）直接转化 → 副词**：100%以 **イ段音** 或 **エ段音** 结尾，强制写为纯平假名，原动词常已消亡（如 *つまり、やはり、しきりに、あまり、さぞ、いきおい、あいにく、とりわけ、あらかじめ、かねがね、たえず、すべからく*）。
* **路径三：述语连用形 + 格助词（に / と）→ 副词**：如 *現に、別に、特に、わざと、静かに、早く*。

## 第二部分：实战举例——三重词汇层的动态博弈解剖

为了直观展示“和语（情感核心）— 汉语（制度/抽象骨架）— 外来语（现代/缓冲插件）”在同一个句子中的动态拉扯，我们来看一句极具现代日本职场与生活张力的句子：

**例句：**

> 「会社のリストラという現実を突きつけられ、あえてローンを組んでまで手に入れたマイホームを、泣く泣く手放すことになった。」

**翻译：**“被冷酷地摆出了公司裁员这一现实，最终不得不含泪卖掉自己硬是背上贷款才买到手的房子。”

在这个句子里，三种词汇层上演了一场极其精妙的认知分工与博弈。

### 1. 【三元词汇层动态博弈：情感、骨架与缓冲】

* **汉语词（制度与冷峻现实的“概念胶囊”）：会社（かいしゃ）、現実（げんじつ）**
  * 博弈功能：这两个词以音读形式出现，不带任何个人体温，负责搭建客观、不可抗拒的外部制度与物理现实骨架。它们被封存在体言模块中，充当冷冰冰的背景板。
* **外来语（现代插件与“情感缓冲垫”）：リストラ（restructuring）、ローン（loan）、マイホーム（my home）**
  * 博弈功能（极致的心理绝缘）：
    1. **リストラ（裁员）**：如果改用汉语词「人員削減（じんいんさくげん）」或和语「首切り（くびきり，砍头/开除）」，文字的血腥感与残酷度会瞬间爆表。用片假名 リストラ 就像戴了一层橡胶手套，把残酷的失业危机包装成一个中性的“企业结构重组”工具词，起到了缓冲心理冲击的作用。
    2. **ローン（贷款）**：刻意避开沉重刺耳的汉语词「借金（しゃっきん，欠债）」，用轻巧的外来语 ローン 稀释负债的羞耻感与压迫感。
    3. **マイホーム（自己的家）**：对比和语「家（いえ，侧重家族/房屋实体）」与汉语「住宅（じゅうたく，侧重房产建筑）」，片假名 マイホーム 承载了战后日本中产阶级“通过个人奋斗拥有专属幸福空间”的现代消费文化符号。
* **和语（切身痛感与全句“CPU指令集”）：突きつけられ（被戳到面前）、あえて（偏偏/硬是）、組んで（背负/组建）、手に入れた（弄到手）、泣く泣く（含泪）、手放す（撒手/放弃）、ことになった（落得如此境地）**
  * 博弈功能（情感爆发与句法主控）：全句真正直击人心、带有强烈身体动作画面与生命痛感的词汇，100%全部由原生和语述语承担！
    * 从极具物理攻击性的 **突きつける**（把刀或现实猛地戳到眼前），到充满身体辛劳感的 **手に入れる**（伸手抓进手里），再到最后极其悲凉的 **泣く泣く手放す**（一边流泪一边松开紧握的手），和语把说话人从“拼命抓住”到“被迫松手”的具身痛苦刻画得淋漓尽致。
    * 同时，所有的格助词（の・を・て・まで・に）与句尾定调的 **ことになった**，牢牢掌控着全句的语法运转。

### 2. 【宏观句法与微观派生速览】

* **句法双螺旋**：前半句将 [会社のリストラという現実] 打包成体言模块，交由被动述语 突きつけられ 承接；后半句将 [あえてローンを組んでまで手に入れたマイホーム] 整体体言化为宾语，最后通过形式体言 こと 打包整个放弃动作（手放すこと），由句尾和语述语 になった 完成无可奈何的命运定调。
* **动词系副词脱敏**：
  * **あえて**（路径一：动词「敢える」演变，剥离“勉强忍受”的动作，转化为表示“明知艰难却偏偏/硬要”的态度副词）。
  * **泣く泣く**（路径二：动词「泣く」终止形重叠副词化，保留了流泪的具身情感渲染，修饰后面的 手放す）。
* **历时音韵透明性**：組んで ← 組みて（`m` 鼻音触发拨音便并浊化 `t → d`）；なった ← なりたり（词尾弹音 `ri` 脱落触发促音便）。

至此，一套融合了历时音韵透明性、词法述语中心↔句法体言后置双螺旋、以及三元词汇层认知分工的完整日语分析体系与 Agent 提示词已经全部构建完毕。你可以随时用它去解剖任何复杂的日语文本。
