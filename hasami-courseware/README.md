# はさまれた自動詞 ・ 宾语を＋V自て＋V他

一本把「**宾语先登场、状态夹中间、他動詞在句末收束**」这个日语语序习惯装进口袋的课件。

```
父の話を ／ 下を向いて ／ 聞いていた。
  宾语     ／  V自て     ／  他動詞
```

很多学习者看到「を」后面紧跟一个**自动词**会慌：其实「を」一直属于句末的**他動詞**，
中间的て形只是**付帯状況**——以什么姿势（座って・立って・横になって）、什么表情
（うなだれて・うつむいて・笑って）、什么心情（ドキドキして・ハラハラして）、什么节奏
（急いで・のんびりして）去做那件事。

遇到新句型随手丢进 `hasami.json`，重跑一次 `build.py`——卡片、发音、题库自动重新长出来。
成品是单文件 `index.html`（内嵌全部发音＋Nadeshiko 原声，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/hasami-courseware/
```

## 五大分類（81 型）

| 组 | 内容 | 例 |
|---|---|---|
| 🧍 姿勢・体勢（10） | 坐着・站着・躺着・蹲着 | 座って・立って・横になって・寝転んで・しゃがんで・正座して・寄りかかって… |
| 😊 表情・感情（38） | 脸和心里的状态先发生 | 下を向いて・うなだれて・うつむいて・笑って・泣いて・涙ぐんで・怒って・震えて… |
| 🌀 心の動き（16） | 心跳与情绪也夹进句子里 | ドキドキして・ワクワクして・ハラハラして・うずうずして・もじもじして・夢中になって… |
| 🏃 速度・テンポ（7） | 做事的节奏也是状态 | 急いで・慌てて・焦って・落ち着いて・のんびりして・ぐずぐずして・だらだらして |
| 🫥 態度・様子（10） | 不说不动也是一种方式 | 黙って・じっとして・うっかりして・きょとんとして・堂々として・平然として… |

每型配 2–3 个「〔名詞〕を＋（この状態）＋他動詞」例句，附 Nadeshiko 真实原声场景卡
（缩略图＋▶），全部 TTS 发音与振假名。

## 增长闭环：发现句型 → 入册 → 重建

### ① 找素材：nadeshiko 原声

```bash
nadeshiko search "下を向いて" --exact --once -n 12   # 真实番剧/日剧台词（必带 --once）
```

- 真实台词按结构 `{ "jp","en","cn","media","ep","at","url","audio","thumb" }`
  放进条目的 `nadeshiko[]` 数组，build 自动下载原声/缩略图并 base64 内嵌（离线）；
- 例句为自写整理（语法型），TTS 负责发音；
- jp 里的汉字一律用「」，别写裸 ASCII 双引号。

### ② 入册：往 hasami.json 里加一条

```jsonc
{
  "id": "shitamuki",            // 全局唯一，定了别改（错题本靠它记忆）
  "word": "下を向いて",           // 展示用て形（同时是填空题挖空单位）
  "read": "したをむいて",         // 假名读音，也是单独朗读的文本
  "base": "下を向く",            // 辞書形（卡片徽标显示）
  "group": "hyojo",             // 必须是 groups 里存在的 id
  "level": "N3", "emoji": "🙇", "tag": "姿勢＋表情",
  "meaning": "低着头、视线朝下——以这种姿势做后面的他動詞",
  "pattern": "父親の話を下を向いて聞く",   // 典型句（可省略）
  "examples": [ { "jp": "……", "cn": "……" } ],
  "nadeshiko": [ /* 见上 */ ],
  "note": "💡 教学提示（金色小贴士，可省略）"
}
```

### ③ 重建：一条命令自动生长

```bash
python3 build.py           # 新音自动合成；働き認識／型填空／聴解判別各 +N 問
```

## 题库

- 📘 **働き認識**：这个て形在句里做什么（从释义里选）
- ✍️ **型填空**：把夹在宾语和他動詞之间的て形找回来（干扰项＝其它型）
- 🎧 **聴解判別**：听例句选型
- 另有 **🎲 混合交错** 与 **📕 错题本**（`localStorage` 键 `hasami-wrong`）

## 音频规格与缓存

- 发音：`edge-tts`（ja-JP-Nanami，-6%），按文本哈希缓存到 `audio/`
  （`audio/{logical_id}-{sha1(text)[:10]}.mp3`，可提交；改句自动重录，stale 自动清理）；
- Nadeshiko 原声/缩略图：`nade_audio/` 缓存（已 gitignore，可重新下载），build 时内嵌进 HTML；
- 振假名：`pykakasi` 只作用于展示副本（Nadeshiko 自带 `漢字(かな)` 先转 ruby）。

## 构建

```bash
python3 build.py
```

重复构建全走缓存；某条 TTS/Nadeshiko 失败只跳过该条，课件照常生成。
依赖：`edge-tts`、`pykakasi`（Nadeshiko/缩略图下载只用标准库 `urllib`）。
