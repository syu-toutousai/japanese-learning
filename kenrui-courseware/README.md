# 兼類詞・両刀ポケット（名词・形容动词兼类词 口袋图鉴）

一个**会长大**的词汇口袋：专门收集「本来当名词、却还能再接『な』当形容动词」的词
（动词连用形名词化 → 形容动词化，语言学上称「名詞・形容動詞の兼類詞」）。

遇到新词随手丢进 `kenrui.json`，重跑一次 `build.py`——卡片、发音、题库自动重新长出来。
成品是单文件 `index.html`（内嵌全部发音，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/kenrui-courseware/
```

## 黄金法则（什么能加「な」）

1. **单纯动作→只能の**：「翻訳の仕事」✓「翻訳な仕事」✗——还在“正在发生”的动态名词不加な；
2. **变成属性/标签→能加な**：おすすめ＝“推荐的动作”→商品的“属性”→おすすめな商品 ✓。
   「な」是把动作贴到物品身上的“贴标签信号”；
3. **新词长得最快**：口语／SNS／广告是温床（こだわりな設計、お気に入りな音楽、進みな技術…）。
   小说或剧里看到的困惑用法，随手丢进本口袋一起解析。

## 增长闭环：查词 → 入袋 → 重建

### ① 查：用 moji 查词条、抄例句

```bash
moji おすすめ --once                    # 释义、JLPT 标签、编号例句＋中文译文
printf "1\n" | moji おすすめ --once     # 改选第 2 个候选
printf "0\n" | moji おすすめ -a --once  # 可选：把单词/例句发音下载到 ~/moji_audio/
```

- 从输出里抄：`word`／`read`／例句 `jp` 与译文 `cn`；
- 若想把 MOJi 原生 mp3 直接当课件发音：把文件拷进 `moji_audio/`，
  条目写 `"readAudio": "moji_audio/xxx_f003.mp3"`（单词读音）、
  例句写 `"audio": "moji_audio/xxx.mp3"`（例句读音），build 会用原生音替掉 edge-tts；
- 想要真实番剧/日剧台词：`nadeshiko search <词> --once -n 5`，选规范用法，按结构
  `{ "jp","en","cn","media","ep","at","url","audio","thumb" }` 放进条目的
  `nadeshiko[]` 数组，build 会自动下载原声并渲染场景卡（缩略图＋▶）。

### ② 入袋：往 kenrui.json 里加一条

```json
{
  "id": "murigachi", "word": "無理", "read": "むり",
  "verb": "無理する",
  "group": "sahen", "level": "N3", "emoji": "💪",
  "meaning": "勉强、强求、不可能",
  "na": "無理な＋要求／スケジュール",
  "examples": [{"jp": "無理な要求ばかりしないでください。", "cn": "别老是提些强人所难的要求。"}],
  "note": "词典级；也单用「無理だ」＝不可能。"
}
```

### ③ 重建：一条命令自动生长

```bash
python3 build.py           # 新音自动合成；詞義認識／運用填空／聴解判別各 +1 問
```

## 条目字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✔ | 全局唯一，字母数字-`_`；定了别改（错题本靠它记忆） |
| `word` | ✔ | 展示词形（名・形動兼類词本体） |
| `read` | ✔ | 读音（假名），也是单独朗读的文本 |
| `verb` |  | 語源動詞（如 勧める→おすすめ），显示为「語源」徽标 |
| `group` | ✔ | 分组 id（顶部 `groups` 定义名称与配色） |
| `level` | ✔ | JLPT 档位标签 N1–N3（兼类词偏中高级） |
| `meaning` | ✔ | 中文释义（「認識」题的答案来源） |
| `na` |  | 常用「な」搭配（如 無理な＋要求），显示在意思框里 |
| `emoji` |  | 卡片图标，缺省 📌 |
| `examples` | ✔≥1 | 例句 `jp` + 中文 `cn`；每句自动合成发音 |
| `nadeshiko` |  | 原声台词数组（见上），渲染成「🎬 原声台词」场景卡 |
| `note` |  | 金色小贴士（语感/构词/规范提醒） |
| `quizzes` |  | 自作题：`choice` / `judge` / `listen` |

> 同类型内置字段：`readAudio`（词读音用 MOJi 原生 mp3）、例句 `audio`（MOJi 原生音）、
> 例句 `src: "moji"`（显示 MOJi 绿标）。

## 内容页签

🗺️ **一覧**（按 5 大分类总览）→ 📖 **詳細**（卡片＋な搭配＋例句原声＋🎬 原声台词场景卡）→ 🎯 **クイズ**

内置 27 词起步，按语义场分 5 组；其中 25 词附 🎬 **Nadeshiko 原声台词场景卡**（50 个真实
番剧/日剧片段，内嵌原声＋截图，离线可听可看：「な 用法」样本如「嫌みな連中」「控えめな渚」、
「場違いなところ」等；進み 未收录——全库无规范性「進みな」用例，宁缺毋滥）。标注
「新兴・口语」的（進み・遅れ・間違い・空回り・遠慮 等）多为廣告/网络演化，
写作时请优先用词典级标准形（進んだ・遅れた・間違った・無駄な・遠慮のない）——这也是本
口袋的教学重点：**既认得な化，也分得清规范**。

## 重新构建

```bash
python3 build.py
```

- 发音按**文本哈希**缓存于 `audio/*.mp3`，改句自动重录、旧缓存自动清理；
- 某条合成失败只跳过该处播放键，不影响整体构建（结尾列出失败清单）。
