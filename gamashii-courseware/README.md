# 〜がましい 構え学 ・ 从构え到慈悲

内容型课件（手写单文件 `index.html`，无构建脚本・无音声・无题库）。

一条线：**構え（摆出的形）→ がましい（形超过实体）→ 人设（形做成社交媒体）→ 慈悲（看穿后不拆）**。

- **① 历史语言学**：構える 的三层语义（建造／姿势／心态）→「構え＋〜しい → かまし → がましい」的浊音化；语义机制＝「形强・实弱・越界」；附「晴れがましい」非贬义検品；**「〜しい」家族**——名詞・連用形＋連結要素（直接／々／か／ま／も／め／が／めか／がま）＋しい 的全景表
- **② 词汇分类与辨析**：越界型（差し出がましい・押し付けがましい）／演出型（恩着せ・言い訳・未練・恨み）＋ らしい／っぽい／がましい 三方辨析（机制・评价・能产性・文体）
- **③ 社会学**：意識高い系 与 凡尔赛／人设（「系」为什么把夸奖变揶揄）
- **④ 商业**：标准锁定（MUJI・山姆・仓储式）vs 空间／信息压缩（电子价签・私域二维码的表里双层）
- **⑤ 哲学**：权利金融化（闲鱼套利）；人艰不拆＝智识×定力×慈悲（含三条検品：「不拆≠不防」等）

打开 `index.html` 即可（或本地 serve）。
