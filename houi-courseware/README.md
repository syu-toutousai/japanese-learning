# 方角・方位 ・ 认知罗盘（houi-courseware）

一套专门按**人脑空间认知规律**编排的方位词课件，目标是掌握「东南西北・左右上下」及它们的派生词
——不靠死记，靠**大脑天生的那张地图**。

成品是单文件 `index.html`（约 1.2MB，内嵌全部发音，离线可用），数据在 `houi.json`。

## 打开

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/houi-courseware/
```

或浏览器直接双击 `index.html`。

## 认知设计（为什么这样编排）

| 页签 / 模块 | 对应人脑机制 |
|---|---|
| 🧭 **罗盘视觉图**（一覧顶部） | 双重编码 dual coding：每个方位同时给「字形＋读音＋图上位置」 |
| **绝对坐标**（东南西北）vs **自身坐标**（左右上下）分组 | 分清坐标系：东南西北以天地为参照、不随身体转动；左右上下以身体为参照、随转身而变 |
| 每个词一条 🧠 **记忆锚** | 具体化 imagery / 生成效应：东＝日出、北＝面向东方伸左手 |
| **对立结伴**（東⇄西・南⇄北・右⇄左・上⇄下，专门的认知卡） | 配对联想 paired-associate：记一个反推一个 |
| 「向かって右/左」**心理旋转**认知卡 + 空间判断题 | 心理旋转 mental rotation：面对面时左右相反，刻意练这个易错点 |
| 组块分 4 组（罗盘/自身/方位名词/方位动作） | 组块化 chunking |
| ✍️ 対立填空（挖掉方位词选回） | 生成效应 generation effect |
| 🎧 聴解判別 | 声音与形义绑定 |
| 🧭 空間判斷（罗盘几点钟方向） | 空间定位 spatial navigation |
| 🎲 混合交错 + 📕 错题本 | interleaving 交错练习 + error-driven review |

## 内容

- **18 个方位词**，分 4 组：
  - 🧭 罗盘・四方（绝对坐标）：東・西・南・北
  - 🧍 自身・三轴（自身坐标）：右・左・上・下
  - 🗺️ 派生・方位名词：東側・西側・東口・南向き・北西・東西南北
  - 🚦 派生・方位动作：右折・左折・上り・下り
- **2 张认知卡**：向かって右/左（心理旋转陷阱）・対になる覚え方（对立结伴）
- **题库 5 层**共 65 问：詞義認識 18・対立填空 18・聴解判別 18・空間判斷 6・自作題 5
  ＋ 錯題本（localStorage，做对即移出）＋ 混合交错模式。

## 数据字段（houi.json）

每条词项：

```json
{
  "id": "higashi", "word": "東", "read": "ひがし", "group": "compass",
  "level": "N5", "emoji": "🌅", "kind": "compass", "dir": "east",
  "meaning": "东；东方（太阳升起的方向）",
  "anchor": "记忆锚：東＝日出的方位。",
  "opp": "nishi",
  "examples": [{"jp": "太陽は東から昇る。", "cn": "太阳从东方升起。"}],
  "quizzes": []
}
```

| 字段 | 说明 |
|---|---|
| `id` | 全局唯一，定了别改（错题本靠它记忆） |
| `group` | 所属分组 id |
| `kind` | `compass`（绝对坐标）/ `axis`（自身坐标）/ `derived`（派生词） |
| `dir` | 罗盘方位英文（`east/north/...`），`compass` 词用于空间判断题 |
| `opp` | 对立伙伴 word 的 id（可留 `"nil"`） |
| `anchor` | 🧠 记忆锚：给大脑的认知钩子 |
| `examples` | 例句 `jp` + `cn`，自动合成发音 |
| `quizzes` | 自作题 `choice`/`judge`/`listen` |

想加词：抄一条改字段 → `python3 build.py` → 刷新，卡片/发音/题目/罗盘自动重建。

## 重新构建

```bash
python3 build.py
```

发音按文本哈希缓存于 `audio/`，改句子自动重录；不再引用的旧缓存自动清理；某条失败只跳过该处
播放键，不影响整体构建。

・`../keiji-courseware/`（接辞口袋）。
