# 呼応・搭配 完全体系 · 交互式学习课件

把 **JLPT N1 過去問（2010-07 ～ 2025-07）** 問題5 文法選択・問題6 並べ替え に出題された
**呼応（こおう）・助詞搭配**を、6 類型 × 167 パターンに再編した単文件・離線可用课件
（`index.html`，内嵌全部音声・画像・真題・題庫）。

## 核心理念：呼応 ＝ 前項が後項を予告する

日本語の上級文法には、**前半の副詞・助詞・文型が、後半の述語の形をあらかじめ指定する**型がある。
二者は必ずセットで現れ、片方だけでは文が決まらない。これが「呼応」であり、N1 問題5/問題6 の中心的考点である。

| 類型 | 例 | 呼応の形 |
|---|---|---|
| A 仮定・譲歩 | たとえ〜ても・どんなに〜ても・いくら〜ても | 前項を極限へ → 後項は不変 |
| B 全面否定 | 決して・いっさい・なんら・必ずしも〜ない | 副詞が否定を予告 |
| C 推量・様態 | どうやら〜ようだ・あたかも〜かのごとく・はたして〜だろうか | 副詞が推量/比況を予告 |
| D 強調・程度 | せめて〜だけでも・なんと〜ことか・〜にもほどがある | 限定と感嘆 |
| E 文末モダリティ | 〜に違いない・〜はずだ・〜おそれがある・〜にほかならない | 述語で断定/推量 |
| F 助詞系文型 | 〜を機に・〜を受けて・〜をもって・〜ならではの・〜とあって | 助詞が搭配を決定 |

## 内容

- **167 個の呼応・搭配パターン** × 6 類型（＋未分類は真題総覧で参照）
- **532 問の真題**を全量収録（問題5 文法選択 270・問題6 並べ替え 135・問題7 文章文法 127）
  - 各問に **完整題干・選択肢・正解・出典（年度・月・問題番号）・校対状態**を明記
- **五層題庫**：🎯 真题填空（405 問・原題そのまま）/ 📘 意味認識 / 🔧 呼応拆解 / 🎧 聴解判别 / ⭕ 判断正誤 ＋ 错题本
- **270 句 TTS 発音**（edge-tts）+ **126 段 Nadeshiko 原声**（含画面缩略図）
- **六層 Tab**：🏛️ 呼応の原理 / 🗺️ 体系図 / 📖 詳解 / 🔍 対比 / 📝 真題総覧 / 🎯 クイズ

## 重新构建

```bash
# 1) 从姊妹仓库 jlpt-n1-question-bank 重新抽取真題 → koou.json
python3 extract_bank.py        # 需先存在 /home/naruto/scratch/jlpt-n1-question-bank
# 2) 构建单文件课件（TTS 内容寻址缓存，句子变了自动重录）
python3 build.py
```

`extract_bank.py` 做三件事：
1. 读取 `jlpt-n1-question-bank/past-exams/<年>/<月>/grammar/*.json`；
2. 用 `CATALOG` 里的匹配规则（正解文字 / 題干触发词）把每题挂到对应呼応パターン；
3. 解析该仓库 `analysis/<session>-grammar-choice.md` / `-composition.md` 里的 Nadeshiko 台词，
   连同真題一起写进 `koou.json`。

## 扩充（增长闭环）

- **加真題**：在 `jlpt-n1-question-bank` 录入新场次 → 跑 `extract_bank.py` → `build.py`，
  真題・題庫・発音が自動で長える。
- **加/改パターン**：在 `extract_bank.py` 的 `CATALOG`（精细パターン）或 `EXTRA`（`_P(...)` 简写）里
  追加一条，指定 `ans`（正解文字）与 `stems`（題干触发词）→ 重新抽取即可。
- **校対**：`koou.json` 的每个 `exams[].verified` 记录题库校対状态；答案键来自
  `jlpt-n1-question-bank/refs/<session>_keys.json` 等（见该仓库 `guides/source-log.md`）。
