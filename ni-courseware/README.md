# 断定の「に」完全体系 · 交互式学习课件

基于 Hub-and-Spoke 模型的 JLPT N5–N1 断定「に」语法家族课件（`index.html`，离线可用）。

## 核心理念

70%以上的中高级日语接续语法都是断定の「に」在做不同风格的力学支撑。
N5→N1 不是六座独立的山，而是同一个 Hub-and-Spoke Wheel 的不同辐线：

- **Hub（轴心）**：断定の「に」（Ren'yōkei of なり / にあり）
- **Spokes（辐线）**：する / よる / 際する / 関する / ついて / 連れる / 従う / 反する…
- **原始残留（直系）**：裸「に」連用修飾語（静かに・実際に）—— なり連用形本身，不是语法化动词

$$\text{[名词短语]} + \text{[（断定）に]} + \text{[语法化动词]} + \text{[可选助词]}$$

> **品詞观**：日语没有「副词」这个独立品詞。体言↔用言 是唯一的实词轴，
> 修饰也只有两个方向：**連体修飾語**（な ← なる／連体形，修饰体言）和
> **連用修飾語**（に ← なり／連用形，修饰用言）。二者是同一条血脉的两张面孔。

## 六大 Lineage

| Group | 代表语法 | JLPT | 力学 |
|---|---|---|---|
| する系 | にする / にしては / にしても | N5–N1 | に锁定现实，する处理它 |
| よる系 | によると / によって | N4–N2 | に建立来源，よる追溯路径 |
| 時空向量系 | に際して / にあたって / に先立って / にあって | N2–N1 | に锚定里程碑，动词定位时空 |
| 関連系 | について / に関して / に対して | N4–N3 | に钉住对象，动词定向注意力 |
| 推移系 | につれて / に従って / にともなって / に反して | N3–N2 | に固定参数，动词协调反应 |
| 連用系 | N・形動語幹＋に（連用修飾語） | N5–N5 | に就地成为连用修饰语，修饰用言（なり連用形直系残留，与連体「な」对偶） |
