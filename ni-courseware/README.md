# 「に」完全体系 · 三本柱 · 交互式学习课件

基于「三本柱（Grand Unified Theory）」模型统一解释日语「に」全部用法的课件
（`index.html`，离线可用）：**断定（Assertive）· 格助詞（Case Particle）· 状態接続（Adverbial Bridge）**。

## 核心理念：にの三本柱

テキスト中のどんな「に」も、この三本の柱のどれかにきれいに収まる。

| 本柱 | 名前 | Syntax | Mechanic | 代表 |
|---|---|---|---|---|
| 第一 | 断定の「に」 | 名詞／形動語幹＋に＋なる・する | 状態・身分を断言し現実として確定 | 医者になる・静かにする |
| 第二 | 格助詞の「に」 | 名詞＋に＋用言 | 現実の座標（位置/方向/相手/時点）にピン留め | 東京に行く・三時に始まる・友達にあげる |
| 第三 | 状態接続の「に」 | 節（未然形＋ず 等）／条件名詞＋に＋用言 | 事態・状態を丸ごと述語の様態副詞に変える | 知らずに恋に落ちた・涙ながらに語った・思うがままに描く |

70%以上の複合語法（について・によって・につれて…）は、第二本柱の格助詞が動詞と複合した拡張。
N5→N1 は独立した山ではなく、同じ「に」エンジンの三つの顔である。

### 第三本柱（状態接続）の収録語法

`〜ずに` / `〜ながらに` / `〜ままに` / `〜がまま（に）` / `〜ゆえに` / `〜ことに` /
`〜うちに` / `〜わりに` / `〜かわりに` / `〜ために`

## 扩充

往 `ni.json` 里加一条语法点（按现有格式），再跑 `python3 build.py`——
卡片、发音、题库全部自动重新长出来。

新 Group 需带 `line` 字段（`line1` / `line2` / `line3`），🏛️ 三本柱タブ会自动把它
收纳到对应本柱之下；`lines` 数组定义三本柱的名称/Syntax/Mechanic。
