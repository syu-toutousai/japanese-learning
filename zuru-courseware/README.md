# ずる⇄じるの系譜（ずる・じる二重動詞系譜）

用「**漢語＋する → 連濁でずる → 上一段化でじる**」的三阶梯镜头，俯瞰日语里
成对的「ずる／じる」动词：

> 論ずる／論じる ・ 信ずる／信じる ・ 感ずる／感じる ・ 演ずる／演じる ・
> 通ずる／通じる ・ 応ずる／応じる ・ 生ずる／生じる ・ 命ずる／命じる ・
> 重んずる／重んじる ・ 甘んずる／甘んじる …

一条词 = **語幹 → ずる形（サ行変格）→ じる形（ザ行上一段）** 的系谱链路。
全部例句 pykakasi 振假名，并配 Nadeshiko 真实台词原声场景卡。成品是单文件
`index.html`（约 10.7MB，内嵌全部音声，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/zuru-courseware/
```

| 组 | 语数 | 代表词 |
|---|---|---|

| 長音「う」系 | 12 | 通じる・応じる・生じる・講じる・投じる・報じる・長じる・乗じる・動じる・高じる・封じる・興じる |
| 二重母音「い」系 | 3 | 命じる・詠じる・映じる |
| 和語＋ん＋ずる | 6 | 重んじる・軽んじる・疎んじる・肯んじる・甘んじる・安んじる |

## 核心机制

| 阶段 | 例（論） |
|---|---|
| ① 名詞＋する | 論（ろん）＋する（漢語を述語にする最小装置） |
| ② 連濁でずる | ん＋すの連濁 → **論ずる**（サ行変格・漢文訓読調） |
| ③ 上一段化でじる | **論じる**（ザ行上一段・現代口語の主役） |

「愛する・発する・達する・接する」のように「する」のままの語も多い——
ずる組は歴史的に固定された語彙の集合で、撥音・長音はあくまで相性の良い条件。
「重んずる・軽んずる・甘んずる」は和語形容詞に撥音「ん」を挿入する別型。

## 题库（7 层 + 错题本）

- 💱 **ずる⇄じる 対応**：给ずる形选对应的上一段形
- 🧬 **活用の型**：サ行変格 or 上一段？（両形各一問）
- 🌀 **活用形ドリル**：未然形（〜ない）・仮定形（〜ば）・命令形（ぜよ／じろ）
- ✍️ **運用填空**：例句中实际出现的活用形挖空选回
- 🎧 **聴解判別 / 意味理解 / 書き取り**：听例句选词 / 选义 / 选原句
- 错题本 localStorage 键：`zuru-wrong`；外加「混合交错」「错题重练」

> 注意：JSON 字符串值里禁止裸 ASCII 双引号，中文引语一律用「」。
