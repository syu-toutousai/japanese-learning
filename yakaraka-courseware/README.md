# 〜やか・らか 形容動詞図鑑

一本把「**和语ナ形容词是怎么长出来的**」做成图鉴的课件：`〜やか`（賑やか・爽やか・華やか…）与
孪生的 `〜らか`（明らか・清らか・安らか…），加上接尾辞融入词的 `〜か`（静か・確か・豊か…），
以及同根、同义场的 `〜しい` 形（華々しい・清々しい・若々しい…）。四族 **67 词**，
每词给出 **核心意象・汉字要素（读法+字义）・同根词族・例句**，把「一个汉字带出一串词」的
构词网络一次铺开——顺带熟悉 16 个常用汉字的音训与派生。

成品是单文件 `index.html`（内嵌全部发音，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/yakaraka-courseware/
```

## 四族与判定

- **〜やか**（24 词）＝にぎわい・華やぎ・柔らかな動き——「生きた状態」
- **〜らか**（11 词）＝澄み・明るさ・平らかさ——「静かで澄んだ状態」
- **〜か**（17 词）＝接尾辞融合、看不出构造的基本状态词
- **〜しい**（15 词）＝「そう感じる」形容詞，与 やか/らか 同根（華やか↔華々しい、清らか↔清々しい）

### 同源対応の四つの型（`shi_frames`）

`〜しい` 侧按接尾辞分四型，这是把两族串起来的框架（体系図页有专卡）：

| 型 | id | 对应例 |
|---|---|---|
| 〜々しい | `dots` | 賑やか↔賑々しい・華やか↔華々しい・艶やか↔艶々しい・清らか↔清々しい・細やか↔細々しい・軽やか↔軽々しい（＋文語 若やか・荒らか） |
| 〜めかしい | `meka` | 艶やか（あでやか）↔艶めかしい（同族：色めかしい） |
| 〜がましい | `gamashi` | 晴れやか↔晴れがましい（同族：未練がましい・押しつけがましい） |
| 〜しい／〜ましい | `shii` | 愚か↔愚かしい・誇らか↔誇らしい・疎か↔疎ましい・麗らか↔麗しい（同字异词） |

判定要点：不管哪一族，**活用都是普通形容動詞**（〜な＋名詞／〜に＋動詞／〜だ）；
`〜やか／〜らか` 是**非能产**的语幹形成接尾辞（不能自由造新词）；汉字写词幹、接尾辞写假名。

## 增长闭环

`yakaraka.json` 加一条 → `python3 build.py` → 卡片、振假名、发音、题库自动长出：

```jsonc
{
  "id": "nagoyaka",
  "word": "和やか", "read": "なごやか", "group": "yaka",   // yaka / raka / ka / shi
  "level": "N1", "emoji": "🍵",
  "core": "气氛柔和融洽、没有紧张——和睦、温和",              // 核心意象
  "mean": "和睦；温和",                                      // 短释义（题库选项用）
  "kanji": [ { "c": "和", "read": "なご", "mean": "和、和睦" } ],
  "related": ["和む（なごむ）", "にこやか"],
  "shi": "niginigishii",          // 同根〜しい 词的 id（可选，交叉链接）
  "frame": "dots",                // 〜しい 词用：dots/めかしい=meka/がましい=gamashi/shii（体系図的四型）
  "examples": [ { "jp": "会談は終始和やかな雰囲気で進んだ。", "cn": "……", "src": "self" } ],
  "form": "和やかな",              // 首条例句中的实际活用形（挖空出题用）
  "note": "💡 教学提示"
}
```

数据里还有顶层 `contrasts`（対比页）与 `kanji_families`（体系図的汉字家族表），同样随手增删。
注意 JSON 字符串值里禁止裸 ASCII 双引号（用「」）；汉字读音如有 pykakasi 误读，
往 `build.py` 的 `_READING_OVERRIDES` 里加整词覆盖（支持「汉字核心＋假名尾巴」自动拆分注音）。

## 音频

全部由 edge-tts（ja-JP-NanamiNeural, rate -6%）合成，内容寻址缓存于 `audio/`：
`{id}-w-{hash}.mp3`（单词）与 `{id}-eN-{hash}.mp3`（例句）；文本一改自动重录，
stale 文件构建时清理。`audio/` 可提交。

**Nadeshiko 场景卡**：58 词的 `nadeshiko[]` 字段（jp 带行内注音 / en / cn / 剧名 / EP /
时间戳 / 链接 / 音频 / 缩略图）由 `nadeshiko search <词> --exact --once --json` 采集，
构建时下载 CDN 音频与缩略图（缓存于 `nade_audio/`，已 gitignore，可重新下载）并 base64 内嵌，
离线可播。台词只挑该词的规范用法；命中不佳的词（みやびやか・平らか・冷ややか・誇らか・
仄か・清か・艶々しい・細々しい・晴れがましい）暂不配场景卡。
