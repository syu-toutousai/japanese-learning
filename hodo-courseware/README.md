# ほど の構図（「ほど」完全构图）

从一句母语者的疑问出发——

> 自分の無知を**このときほど**強く感じたことはない。

这个「このときほど」到底是体言修饰还是用言修饰？答案：**用言修饰（连用修饰语）**。
「ほど」是**副助詞**，后接用言就构成**連用修飾語**，后接「の＋体言」就切换为**連体修飾語**：

| 後ろに来る語 | 形 | 作る修飾語 | 例 |
|---|---|---|---|
| 用言（動詞・形容詞） | 〜ほど | 連用修飾語（副詞的） | このとき**ほど**強く感じた／死ぬ**ほど**疲れた |
| 体言（名詞） | 〜ほどの | 連体修飾語 | このとき**ほどの**衝撃／声も出ない**ほどの**恐怖 |

课件以此切换为轴，俯瞰「ほど」的程度・最高级・比例・限度・概数全用法。

## 核心机制

1. **品詞**：学校文法（橋本進吉体系）では「ほど」は**副助詞**。体言・連体形に付く。
   形式名詞（こと・もの）ではないので、単独で主語・目的語にはなれない。
2. **修飾**：後続語の品詞で作る修飾語が切り替わる——用言なら連用修飾語、体言なら
   「の」を伴って連体修飾語。
3 **意味**：程度（死ぬほど）・比較/最高級（〜ほど…ない）・概数（三日ほど）の三つの顔。
