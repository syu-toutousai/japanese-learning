# 🔣 日本語 記号と文字の全景 ・ 読む・使う・入力する

日语特殊符号与本土字系统的研习用单文件课件。把假名、国字、变音记号、地图记号、
组文字、约物与 IME 输入法放在同一张地图上：每个记号都给「读音・意味・由来・用法・输入」，
并配 TTS 读音/例句与七层题库。

## 使い方

```bash
cd kigou-courseware
python3 build.py          # 生成 index.html（TTS は audio/ に内容地址缓存）
python3 ../tools/make_lite.py kigou-courseware   # 生成 web-lite.html
```

`index.html` をブラウザで開くだけ。音声は base64 内嵌、外部通信なし。

## 増やし方（增长闭环）

1. `kigou.json` の `items` に一条追加：

```jsonc
{
  "id": "YOUR_ID",                 // 字母数字-_ のみ
  "symbol": "㋿",                  // 表示する記号
  "word": "㋿（令和）",             // 名前（symbol と同じなら一覧で重複表示しない）
  "read": "れいわ",                // 読み（TTS・読みクイズ・聴解に使用）
  "group": "kumimoji",             // groups の id
  "level": "実用",
  "meaning": "令和（年号）",         // 中国語の意味（意味クイズの選択肢）
  "origin": "「令和」の組文字",      // 由来（由来クイズの選択肢）
  "usage": "年号を1字で表す。",      // 使い方（中国語）
  "input": "れいわ",               // IME 入力（空なら入力クイズを生成しない）
  "examples": [
    { "jp": "㋿の時代に入った。", "cn": "进入了令和时代。", "speech": "令和の時代に入った。" }
  ],
  "note": "元号の組文字。"
}
```

2. `python3 build.py` を実行。カード・読み音声・例句音声・各题库が自動で増える。
3. `python3 ../tools/make_lite.py kigou-courseware` で Lite 版も更新。

### データの約束

- `read` が他の記号と重複する場合、読みクイズと聴解クイズは自動でスキップ
  （例：々・ゝゞ・ヽヾ はすべて「くりかえし」）。
- `input` が重複する場合も入力クイズをスキップ（例：㍿ と ㈱）。
- `examples[].speech` は TTS 用の読み上げ文。記号を含む例文では、記号を読みに
  置き換えた自然な文を入れる（省略時は `jp` をそのまま合成）。
- 例文は 1 記号につき 2 条を推奨。`jp` に `symbol` が含まれる場合、用例填空クイズが自動生成される。
- 振り仮名（ruby）は表示コピーだけに付与。TTS・出題・填空は素文を使う。

## 表記・内容の注

- **㌔ はキロメートル**（Unicode: SQUARE KIROMEETORU）。キログラムは **㌕**。
- **🍁（紅葉マーク）は高齢運転者標識**。四葉のクローバー（身体障害者標識）とは別物。
- 地図記号の国際化（卍→三重塔・〒→封筒・文→学士帽・Ⅹ→警官・♨→人形追加）は
  国土地理院の公開資料を参考にした事実説明。断定を避けたい場合は `note` を調整する。
- 組文字（㍿・㌔ など）の見た目はフォント依存。Mac/Windows では
  Hiragino / MS Mincho 系で表示され、Linux の Noto CJK ではグリフが密集して見えることがある。
  読みは必ず併記しているので、内容の理解には影響しない。
- 本课件は **Nadeshiko 原声を含まない**。音声はすべてローカル edge-tts 合成。
