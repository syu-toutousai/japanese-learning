# 連用形の化身（连用形化身）・ 動詞が接尾語になるとき

用「**连用形中顿 → 助词脱落 → 固化**」的镜头俯视接尾语：

> 当たる → 〜あたり ／ 沿う → 〜沿い ／ 越す → 〜越し ／ 向ける → 〜向け ／
> 続く → 〜続き ／ 次ぐ → 〜次第 ／ 放す → 〜っぱなし ／ 塗れる → 〜まみれ ／
> 尽くす → 〜ずくめ ／ 勝つ → 〜がち …

一条词 = **源動詞 → 連用形 → 接尾語化链路**。全部例句 pykakasi 振假名，并配 Nadeshiko
真实台词原声场景卡。成品是单文件 `index.html`（约 2.8MB，内嵌全部音声，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/renyo-courseware/
```

## 核心机制

| 阶段 | 例（沿う） |
|---|---|
| ① 原生态 | 川**に沿う**（挨着河） |
| ② 中顿态 | 川**に沿い**、歩く（顺着河，走） |
| ③ 语法化 | 助词「に」脱落 → 川**沿い**を歩く（接尾语固化） |

同一条路径造出了 〜あたり・〜越し・〜向け・〜続き・〜次第……用这个视角看，接尾语不再是
死记条目，而是「前半句动作顺延到后半句」的活画面。


## 题库（4 层 + 错题本）

- 🌀 **元の動詞**：给接尾语选源动词（〜まみれ ← 塗れる？塗る？塗す？）
- ⛓️ **文法化**：选出「中顿→脱落→固化」的正确道筋
- ✍️ **運用填空**：例句挖掉接尾语选回去
- 🎧 **聴解判別**：听音频判断用了哪个接尾语
- 错题本 localStorage 键：`renyo-wrong`；外加「混合交错」「错题重练」

> 注意：JSON 字符串值里禁止裸 ASCII 双引号，中文引语一律用「」。
