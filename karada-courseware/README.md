# からだの慣用句 ・ 体の部位ポケット

一本按**身体部位**整理 JLPT 常考惯用句与身体动作表达的词汇口袋。

- **慣用句（引申义）**：頭が下がる（敬佩）・顔が広い（人脉广）・目を通す（过目）・
  耳が痛い（刺耳）・鼻が高い（骄傲）・口が堅い（嘴严）・胸を張る（自信）・
  腹を割る（推心置腹）・手を焼く（棘手）・足を運ぶ（特意前往）・骨が折れる（费力）……
- **身体動作（字面义）**：うなだれる・下を向く・うつむく・目を伏せる・顔を背ける・
  耳を澄ます・息をのむ・身を乗り出す・目を輝かせる・腕を組む・体を張る……

遇到新词条随手丢进 `karada.json`，重跑一次 `build.py`——卡片、发音、题库自动重新长出来。
成品是单文件 `index.html`（内嵌全部发音＋Nadeshiko 原声，离线可用）。

## 打开

浏览器直接打开 `index.html`，或起本地服务：

```bash
python3 -m http.server 8642   # 然后访问 http://localhost:8642/karada-courseware/
```

## 🗾 語種（和／漢／混）——身体語彙の二重構造

每条 `origin` 标注语种，界面有徽标＋一覧筛选：

| 語種 | 条数 | 例 |
|---|---|---|
| 和語（训读） | 110 | 手を焼く・足を運ぶ・うなだれる・目安（めやす）・手際（てぎわ）・骨折り（ほねおり） |
| 漢語（音读） | 2 | 手腕（しゅわん）・閉口（へいこう） |
| 混種 | 1 | 怪訝な顔（漢語形容動詞＋和語名詞） |

判定用「読み」而非字形：目安・手際・裏腹・心当たり是训读＝和語；手腕・手芸・目撃是音读＝漢語。
身体慣用句几乎全是大和言葉（部位＋助词＋和语动词的比喩転用），而 JLPT 里被考到的
念頭・胸中・背後・没頭…属于漢語概念层——它们不出卡片，留在 📝 真題 Tab 作语料。
理论篇见 [`meta-guide/` 的「身体語彙の二重構造」](../meta-guide/#body-layers)。

## 📝 JLPT 真題コーパス（jlpt.json）

`fetch_jlpt.py` 从合并题库 `jlpt-question-bank` 的 `n1/` 子树（原 `jlpt-n1-question-bank`，
JLPT N1 2010-07〜2025-07，2746 題）中**穷尽抽取**与身体相关的语料，写入 `jlpt.json`：

- **exams（52 問）**：被考到的身体惯用句/身体部位的语彙题（漢字読み・文脈規定・
  言い換え・使い方）与文法题（文法選択・並べ替え）——原題・选项・正解・出典（年度・月・
  問題番号）・教学 memo 全套，其中 32 問挂接到对应词条；
- **sents（25 句）**：読解/文法篇章里出现的真题例句（足を運ぶ・耳を澄ます・下を向く…），
  逐句标出出典并挂接词条。

课件里以三重方式兑现：

1. **📝 真題 Tab**：真題例文＋出題問題全量展示（正解高亮、N1 出处、词条跳转）；
2. **词条详情**：每个条目下自动列出「🎯 真題例文」「📝 JLPT 出題」；
3. **📝 真題（原題）题库**：51 問原题直接进训练场（选项构建期固定种子打乱）。

```bash
python3 fetch_jlpt.py   # 题库更新后重抽（需要 jlpt-question-bank/n1 在固定路径）
python3 build.py        # 消费 jlpt.json 重建课件
```

加新词条后想被真题自动挂接：在 `fetch_jlpt.py` 的 `EXAMS` 目录里给题目补上 `items=[...]`，
再重跑两个脚本即可。体部位汉词语汇（念頭・胸中・背後…）不出卡片，只留在真題 Tab 作语料。

## 增长闭环：发现词条 → 入册 → 重建

### ① 找素材：moji / nadeshiko 双源

```bash
moji 頭が下がる --once                          # 释义查证（抄释义与例句）
nadeshiko search "頭が下がる" --exact --once -n 12  # 真实番剧/日剧台词（必带 --once）
```

- 真实台词按结构 `{ "jp","en","cn","media","ep","at","url","audio","thumb" }`
  放进条目的 `nadeshiko[]` 数组，build 自动下载原声/缩略图并 base64 内嵌（离线）；
- 释义经 moji 查证后自写整理；例句为自写或改写（保证惯用义成立）；
- jp 里的汉字一律用「」，别写裸 ASCII 双引号。

### ② 入册：往 karada.json 里加一条

```jsonc
{
  "id": "atama-sagaru",          // 全局唯一，定了别改（错题本靠它记忆）
  "word": "頭が下がる",           // 展示用惯用句（部位填空的挖空来源）
  "read": "あたまがさがる",       // 假名读音，也是单独朗读的文本
  "part": "頭",                  // 用来出「（　）が下がる」部位填空题（可省略）
  "group": "head",               // 必须是 groups 里存在的 id
  "origin": "wago",              // 语种：wago（和語）｜kango（漢語）｜mixed（混種）；可省略＝wago
  "level": "N2", "emoji": "🙇",
  "type": "慣用句",              // 慣用句（引申义）｜動作（字面动作）
  "literal": "头低下去（像鞠躬一样）",
  "meaning": "敬佩、佩服；由衷感到尊敬",
  "pattern": "〜には頭が下がる",   // 典型句（可省略）
  "examples": [ { "jp": "……", "cn": "……" } ],
  "nadeshiko": [ /* 见上 */ ],
  "note": "💡 近义/对比/误用提示（金色小贴士，可省略）"
}
```

### ③ 重建：一条命令自动生长

```bash
python3 fetch_jlpt.py      # （可选）真题题库更新后重抽 jlpt.json
python3 build.py           # 新音自动合成；意味認識／部位填空／聴解判別／真題各 +N 問
```

## 音频规格与缓存

- 发音：`edge-tts`（ja-JP-Nanami，-6%），按文本哈希缓存到 `audio/`
  （`audio/{logical_id}-{sha1(text)[:10]}.mp3`，可提交；改句自动重录，stale 自动清理）——
  现行 362 clips（词条读音＋例句＋真题答案句）；
- Nadeshiko 原声/缩略图：`nade_audio/` 缓存（已 gitignore，可重新下载），build 时内嵌进 HTML；
- 振假名：`pykakasi` 只作用于展示副本（Nadeshiko 自带 `漢字(かな)` 先转 ruby；
  `_READING_OVERRIDES` 修正 お手上げ・心当たり・細やか・100年 等误读）。

## 构建

```bash
python3 fetch_jlpt.py   # 从姊妹题库重抽真題コーパス（可选，jlpt.json 已提交）

```

重复构建全走缓存；某条 TTS/Nadeshiko 失败只跳过该条，课件照常生成。
依赖：`edge-tts`、`pykakasi`（Nadeshiko/缩略图下载只用标准库 `urllib`）。
`fetch_jlpt.py` 需要 `/home/naruto/scratch/jlpt-question-bank/n1/past-exams/` 存在；
build.py 只消费已提交的 `jlpt.json`，不依赖题库仓库。
