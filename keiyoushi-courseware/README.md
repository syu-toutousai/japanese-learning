# 動詞系形容詞 ・ 活用形が形容詞になるとき

「改まる → 改まった」「澄ます → 澄ました」「飛ぶ → とんだ」——
**形態は動詞の活用形のままなのに、辞書が連体詞・形容詞として認め、元動詞から意味を直接導けない**語を集めた単文件课件。

- 核心19語＋周辺11語＝30語。
- `keiyoushi.json` に一語追加 → `python3 build.py` → 卡片・发音・Nadeshiko 场景・题库自动生长。
- 生成物：`index.html`（約4.2 MB）＋ `web-lite.html`（220 KB）。

---

## 1. 収録基準（この课件の核心）

1. **形態**：全体が動詞の活用形のまま（例：改まった＝改まる＋た、澄ました＝澄ます＋た）。
2. **辞書認定**：辞書が見出しを**連体詞**または**形容詞**として立てている。
3. **意味の漂白**：元動詞の意味から形容詞の意味を**直接導けない**（導けるなら生産的パターンとして別扱い）。
4. **和語型**：漢語＋する型ではなく、和語の動詞・形容詞を核とする語。

この基準で、核心19語と、連語・俗語として連体詞的に使う周辺11語に分けた。
「読みやすい」「見にくい」「わかりやすい」など、元動詞から意味を直接導ける生産的パターンは核心に入れていない。

### Nadeshiko 誤命中検品

Nadeshiko は同形の動詞・受身・慣用句を大量に拾う。课件内に次の検品表を収録：

| 検索語 | 誤命中 | なぜ違う | 形容詞の用例 |

| いかれた | 連れていかれた | 「行く」の受身・可能 | いかれた奴 |
| やられた | やられた！ | 受身「やられる」の間投詞 | やられた顔 |

## 5. データ形式（`keiyoushi.json`）

```jsonc
{
  "meta": { "title": "...", "titleCn": "...", "jp": "...", "tags": [...] },
  "groups": [
    { "id": "rentai", "name": "連体詞化した〜た（核心）", "color": "#7c3aed",
      "emoji": "🧥", "pathLabel": "連用形＋た（連体詞）", "note": "..." }
  ],
  "items": [
    {
      "id": "aratamatta",
      "group": "rentai",
      "level": "N2",
      "jlpt": "N2",
      "emoji": "🎩",
      "word": "改まった",
      "read": "あらたまった",
      "surface": "改まった",
      "status": "確実",
      "dict": "連体詞",        // 連体詞 / 形容詞 / 連語（連体詞的）
      "drift": "高",           // 意味の漂白度
      "literal": "直訳：改められた → 正式な",
      "origin": "動詞「改まる」の連用形＋たの連体形。",
      "originShort": "改まるの連用形＋た",
      "physical": "改まる。改められて、新しい状態になる。",
      "meaning": "正式的；庄重的；一本正经的",
      "label": "正式／庄重",
      "engine": "「改められた状態」が、改まった席・態度の形容詞に固定した。",
      "examples": [ { "jp": "改まった席では…", "cn": "…", "src": "self" } ],
      "nadeshiko": [],
      "note": "…", "contrast": "…", "pitfall": "…",
      "judge": [], "quizzes": [],
      "freq": { "tier": "D", "stars": 1, "nade": 43, "wf": null,
                "basis": "Nadeshiko 全庫 表層一致", "note": "…" }
    }
  ]
}
```

- `dict`：辞書認定（連体詞／形容詞／連語（連体詞的））。
- `drift`：意味の漂白度（高／中）。元動詞から意味を直接導ける度合いの逆数。
- `literal`：直訳と形容詞義の対比。
- `surface` は少なくとも1つの例句に含める（穴埋め用）。
- `freq` は Nadeshiko 全庫ヒット数から S/A/B/C/D。同形動詞を含む語は `note` に明記。

## 7. 工具与来源

- **MOJi 辞書 CLI**：`moji <語> --once --json …` 采集释义与例句（例句标 `src: "moji"`）。
- **Nadeshiko CLI**：`nadeshiko search <語> --once -n 8 --json …` 采集真实台词、幕/时间戳、CDN 音频与缩略图；`nadeshiko words <語…> --json …` 取全庫ヒット数用于頻度マーカー。
- **edge-tts**：`ja-JP-NanamiNeural`，rate `-6%`，内容寻址缓存。
- **pykakasi**：振假名；`_READING_OVERRIDES` 修正 `落ち着いた→おちついた`、`澄ました→すました`、`かしこまった→かしこまった`、`見窄らしい→みすぼらしい` 等。
- 語源は「確実／通説／諸説」の三段階。意味の漂白は断定ではなく、辞書認定と用例に基づく分類。

## 8. 新增一語の最小手順

1. 在 `keiyoushi.json` 的 `items` 里加一条，`group` 必须是 `rentai`/`nai`/`kogo`/`idiom`。
2. 检查三条件：形態が動詞の活用形か／辞書が連体詞・形容詞と認定するか／元動詞から意味を直接導けないか。
3. 写 3 条例句，确保 `surface` 出现在至少一条例句中。
4. `dict` 填辞書認定，`drift` 填漂白度，`literal` 填直译对比。
5. Nadeshiko 可选；有则填 `jp/en/cn/media/ep/at/url/audio/thumb`。
6. `jlpt` 填 `level` 同值；`freq` 用 `nadeshiko words <語> --json` 取 hit 数，按 S≥2000/A≥700/B≥200/C≥50/D<50 定 tier。未设定时 build 会补 `—`。
7. `python3 build.py`；重跑 `python3 tools/make_lite.py keiyoushi-courseware`。
