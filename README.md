# japanese-learning

个人日语学习资料库。记录学习过程中制作的交互课件与练习材料，便于日后复习。

## 目录

| 内容 | 说明 |
|---|---|
| [`shidai-courseware/`](./shidai-courseware/) | 「次第」完全掌握：四种用法讲解 + 例句原声 + クイズ双题库（基礎15問 / 挑戦10問），单文件 HTML 离线可用 |
